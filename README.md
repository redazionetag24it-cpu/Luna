# Luna V1

Agent Android vocal minimal.

## Ce face
- recunoaște comenzi vocale în română;
- răspunde vocal;
- deschide Chrome, WhatsApp și TikTok;
- păstrează istoricul conversației în ecran.

## Instalare
1. Deschide proiectul în Android Studio.
2. Lasă Gradle să sincronizeze proiectul.
3. Conectează telefonul Android cu USB debugging activat.
4. Rulează aplicația.
5. Acceptă permisiunea pentru microfon.
6. Apasă butonul microfon și spune: „Luna, deschide Chrome”.

## Următoarea etapă
Conectarea la un backend AI, apoi executorul de acțiuni, contacte/apeluri, notificări și Accessibility.
